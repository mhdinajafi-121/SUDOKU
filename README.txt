SUDOKU — PLAYABLE WEB VERSION

To play:

1. Extract this folder.

2. Open index.html in Chrome, Edge, Firefox, or Safari.

3. On mobile, transfer index.html to the phone and open it in a browser, or host this folder on a static web host.

4. Game progress and statistics are saved in that browser's local storage.

For Windows EXE and Android APK:
This HTML version is not itself a native installer. Use the Flutter project included in the companion source archive for native builds. A native build requires Flutter and platform tooling; iOS builds require macOS + Xcode.
